# all-9-lab

ЛАБОРАТОРНАЯ РАБОТА №9 — FETCH API / AJAX
Все три уровня и все 20 вариантов.

БЫСТРЫЙ ЗАПУСК
1. Распакуйте архив полностью в отдельную папку.
2. Откройте index.html в современном браузере.
3. Выберите уровень и вариант. Нажмите кнопку загрузки, если данные
   ещё не загружены. Для получения данных требуется интернет.
4. Откройте report.html: это полный отчёт и ответы на контрольные вопросы.

ЗАПУСК ЧЕРЕЗ ЛОКАЛЬНЫЙ СЕРВЕР
Методичка рекомендует локальный сервер. Этот способ также подходит,
если браузер ограничивает запросы при открытии файла из папки.

Способ 1: VS Code + расширение Live Server.
Откройте папку проекта в VS Code, затем index.html через Open with Live Server.

Способ 2: Python 3.
Откройте терминал в папке, где находится index.html, и выполните:
  python3 -m http.server 8000
В Windows при необходимости:
  py -m http.server 8000
Откройте в браузере:
  http://localhost:8000
Остановка сервера: Ctrl+C в терминале.

СОСТАВ
index.html  — разметка и навигация приложения.
style.css   — оформление и адаптация к экрану.
app.js      — логика запросов и все 20 заданий, с комментариями.
report.html — отчёт, тестирование, скриншоты, исходный код и ответы.
screenshots/ — снимки приложения, использованные в отчёте.

УРОВНИ
Базовый:    варианты 1–7.
Средний:    варианты 8–15.
Повышенный: варианты 16–20.

ЧТО ПОКАЗАТЬ ПРИ ЗАЩИТЕ
• Успешную загрузку списка публикаций.
• Запрос публикации с существующим ID и с ID 9999.
• Фильтр задач, поиск и переключение страниц.
• Пользователь → публикации → комментарии.
• Параллельную загрузку и подсчёт публикаций.
• Поиск с задержкой ввода и отменой запроса.
• Ошибку сети и успешный повтор после восстановления соединения.

ПРОВЕРКА ОШИБКИ СЕТИ
Откройте инструменты разработчика браузера, раздел Network.
Включите Offline и выполните новый запрос: должна появиться ошибка.
Выключите Offline и нажмите «Повторить».

ПРИМЕЧАНИЯ
Данные приходят из учебного JSONPlaceholder и являются демонстрационными.
Если внешний сервис недоступен, приложение показывает ошибку; восстановите
соединение и повторите запрос. Недоступная миниатюра фотографии заменяется
текстом, название фотографии остаётся видимым.

Для печати отчёта нажмите «Печать / сохранить в PDF» в report.html.
Поля ФИО и группы можно исправить перед печатью, нажав на них.
Для сохранения таких исправлений в исходном файле измените report.html
в текстовом редакторе.

Приложению не нужны npm, сборка, аккаунт или ключ API.
HTML, CSS и JavaScript разделены в соответствии с методичкой;
весь проект передаётся одним ZIP-архивом.
